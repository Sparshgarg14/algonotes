## Problem D — Post-mortem

The crux was computing `C(n, k) mod p`. I kept trying to precompute factorials but forgot the inverse factorial step.

```cpp
// Correct approach
long long inv_fact(long long n, long long mod) {
    return power(fact[n], mod - 2, mod);
}
```
